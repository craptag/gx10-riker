GX10 Riker

A private personal assistant for one person.

GX10 Riker is a personal assistant that runs on its owner's own home computer. It is not a public service and cannot be used by anyone else.

With the owner's permission, it connects to the owner's own Google Calendar so that it can:

  • read the owner's upcoming events, to answer questions like "what's on tomorrow?";
  • add events and reminders the owner asks for;
  • change or delete the owner's own events, only after the owner confirms each one.

It never invites other people, never sends emails, and never shares calendar data with anyone.
